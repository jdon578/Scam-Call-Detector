Scam Call Detector app - Capstone project for ICSI 499
Android app using Java through Android Studio

# Features
## Scam Call Blocking
Using both user-inputted phone numbers, our verification, and verification from a global scam database, incoming numbers are scanned for potential harm.

## Reporting numbers
Phone numbers can be reported by users to submit to our database.

## Call Logs and Contacts
Call logs and contacts are pulled from your phone, allowing you to report specific numbers with ease and prevent others from calling you without reporting.

## Information
The app contains information on types of scams and how to keep yourself safe.
